# Mi espacio web

## Descripción
Proyecto escolar con un diseño moderno en blanco y azul y una imagen de paisaje.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Archivos
- index.html: página principal.
- contacto.html: página de contacto.
- css/estilo.css: estilos.
- js/script.js: funciones interactivas.
- img/: carpeta para imágenes.

## Publicación
El proyecto puede publicarse mediante GitHub Pages.
